# Docker Volumes & Networks Lab

## Project Overview
This project demonstrates Docker persistent storage and container-to-container communication.

## Technologies Used
- Docker
- Docker Volumes
- Docker Bridge Networks
- Nginx
- HTML
- Ubuntu Linux

## Project Features
- Persistent data storage using Docker Volumes
- Custom Docker network creation
- Communication between multiple containers
- Nginx web server deployment
- Custom Docker image using Dockerfile

## Docker Volume Commands
